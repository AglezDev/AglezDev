## 🚀 Proyectos Destacados

### 🖥️ **FlexPOS — Modern Offline-First POS System**
*Sistema de Punto de Venta multiplataforma enfocado en alta disponibilidad local y portabilidad.*
* **Stack:** Electron, React, TypeScript, SQLite, IPC Communication.
* **El Reto:** Migración y refactorización de una arquitectura monolítica heredada hacia un modelo asíncrono y orientado a eventos, garantizando una operación *offline-first* ultra rápida.
* **Ingeniería:** Implementación de una capa segura de comunicación IPC entre el proceso principal y el renderizador, manteniendo la coherencia de datos locales sin degradar la experiencia en el punto de venta.
* **AI Acceleration:** Automatización de la traducción de reglas de negocio a TypeScript, configuración del pipeline de empaquetado y generación de componentes UI reutilizables.

### 📱 **Datus — Mobile Telecom & Engagement Hub**

* **Stack:** Kotlin, Jetpack Compose, Android Telephony API, Supabase.

* **AI Acceleration:** Aceleración en la implementación de escuchadores de eventos del sistema Android y optimización de algoritmos de parsing asíncrono.
